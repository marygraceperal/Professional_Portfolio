What This Folder System Is For

The private archive contains the complete working evidence behind the public professional portfolio. It should contain more detailed records than the public repository.

Private Master Archive

Keep the complete working records, drafts, source files, detailed evidence and historical documents here.

Public Evidence Is Curated

Not every private document needs to appear in the public portfolio. Select only the strongest and appropriate evidence.

Consolidate Where Appropriate

Related evidence can be combined into one well-organized PDF rather than creating unnecessary individual files.

Evidence Workflow

How to Build Each Folder

Use the same workflow for every subfolder so the archive remains organized and easy to maintain.

STEP 01

Gather

Collect existing documents, certificates, screenshots, lesson materials and records.

STEP 02

Select

Remove duplicates and keep the strongest evidence.

STEP 03

Organize

Arrange documents logically according to the folder purpose.

STEP 04

Consolidate

Combine closely related evidence into a clear master PDF when appropriate.

STEP 05

Name

Use clear filenames with the project name and year.

STEP 06

Review

Check accuracy, privacy, completeness and professional presentation.

Recommended principle: Your private archive can be comprehensive, but it should not become unnecessarily repetitive. One strong, well-structured PDF can replace many small files when the evidence naturally belongs together.
