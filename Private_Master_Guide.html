Evidence Status System

How to Mark Your Progress

Use one consistent status system throughout your private evidence-building process.

🟢 COMPLETE Evidence exists, is organized and is ready for review.
🟡 IN PROGRESS Some evidence exists but the package is not finished.
🔴 MISSING The document or evidence still needs to be created.
🔵 UPDATE LATER Evidence depends on an activity that has not yet occurred.
⚪ OPTIONAL Useful supporting evidence but not essential to the application.

Evidence Packaging

One PDF or Multiple Documents?

Use the simplest structure that allows another person to understand the evidence quickly.

RECOMMENDED

Consolidated Evidence PDF

Use one PDF when several related pieces of evidence belong to the same project.

  • Cover page
  • Context
  • Core document
  • Supporting evidence
  • Reflection
  • Appendices
USE WHEN NEEDED

Separate Original Documents

Keep documents separate when they have independent value or need to remain in their original form.

  • Official certificates
  • Signed approvals
  • Letters
  • Official forms
  • Employment documents
BEST PRACTICE

Keep the Original

Never replace an important original simply because you created a polished evidence PDF.

  • Original certificate remains stored
  • Evidence PDF provides context
  • Public folder receives only appropriate copies

Final Checklist

Before You Call the Portfolio Finished

📁 Folder Check

  • All seven private folders exist.
  • Duplicate folders have been removed.
  • Documents are stored in the correct category.
  • File names are consistent.

📄 Document Check

  • Important certificates are preserved.
  • Evidence PDFs have clear titles.
  • Dates and names are accurate.
  • No unsupported claims are made.

🔗 Link Check

  • Every portfolio link opens correctly.
  • Google Drive permissions work.
  • Website links work.
  • Public links do not expose unnecessary private material.

🔒 Privacy Check

  • Student personal information is protected.
  • Sensitive records are not publicly accessible.
  • Private originals remain private.
  • Only appropriate evidence is published.

🇳🇿 Application Check

  • CV is current.
  • Teaching philosophy is ready.
  • References are prepared.
  • Evidence supports the claims in the CV.

🎯 Final Principle

  • Quality over quantity.
  • Evidence over claims.
  • Clear organization over excessive documents.
  • Honest status reporting.

Build Evidence, Not Just Files

The purpose of this private system is not to collect as many documents as possible. It is to organize meaningful evidence that demonstrates professional judgment, Mathematics teaching capability, learner support, digital competence, collaboration and continuous professional growth.
